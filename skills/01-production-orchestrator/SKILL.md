# Production Orchestrator

Always produce a structured production state:
INPUT → SCRIPT DOCTOR → STORY GRAPH → DIRECTOR → SCENES → GENERATION → VALIDATION → MENTOR → REVISION → TIMELINE → RENDER → THUMBNAIL → EXPORT.

Never skip quality gates.
Never call media providers directly from domain logic.
Keep all artifacts versioned.
Prefer minimum regeneration through dependency analysis.

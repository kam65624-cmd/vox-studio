# Humanization

Detect:
repetitive framing, repetitive transitions, generic visuals, literal metaphors, identical timing, over-animation, robotic pauses, weak reactions, unnecessary exposition and predictable scene order.

Fix through editorial intent:
contrast, silence, reaction, macro/wide changes, motivated transitions, visual callbacks and selective restraint.

Never introduce randomness merely to appear human.

# Media Render

Pipeline:
probe → normalize → compose → audio mix → captions → transitions → color → render → probe → package.

Validate:
resolution, FPS, duration, audio presence, loudness target, frame integrity, captions, safe zones and export profile.

Never export an unprobed render.

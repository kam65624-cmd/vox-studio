# Asset & Style Compiler

Input:
reference images, sheets, moodboards, logos, palettes and written notes.

Output:
canonical identity, visual constraints, palette, typography, texture, camera, motion, transitions, negative rules, compatibility.

Never treat one generated image as the only source of truth when a reference sheet exists.

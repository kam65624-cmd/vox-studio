# Premium UI

Use:
dark editorial shell, restrained accent palette, cinematic hierarchy, tactile asset cards, quiet motion and dense-but-readable production workspace.

Primary layout:
Asset Rail | Canvas | Inspector/Mentor | Storyboard/Timeline.

Avoid:
generic SaaS cards, rainbow gradients, excessive glassmorphism, excessive glow, decorative animation and dashboard clutter.

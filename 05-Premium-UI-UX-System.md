# VOX Studio — Premium UI/UX System v1.0

## Creative direction
Dark editorial production OS × cinematic studio × modern AI tool.

The interface should feel expensive, quiet and deliberate—not like a generic SaaS dashboard.

## Core principles
1. Canvas first.
2. Information density without visual noise.
3. One primary action per context.
4. Motion communicates state.
5. Assets feel tangible.
6. Mentor feedback feels like a senior editor, not a red error list.
7. No rainbow UI.
8. Accent colors are semantic, not decorative.

## Typography
Display: condensed editorial display family such as Bebas Neue where licensing permits.
UI/Arabic: IBM Plex Sans Arabic or another high-quality Arabic UI family.
Body: neutral sans.
Never use more than 2–3 families.

## App shell
- compact top bar
- minimal left navigation
- command palette
- workspace switcher
- project/episode breadcrumb
- production state
- Mentor score
- render action

## Production screen
Left: Asset Rail
Center: Preview/Canvas
Right: Inspector + Mentor
Bottom: Storyboard + Timeline

## Asset cards
Show thumbnail, type, version, compatibility, usage count, and status.
Canonical assets have a clear canonical marker.

## Scene cards
Show scene number, duration, type, status, mentor score and generation state.
Drag to reorder.
Quick actions: preview, regenerate, replace, duplicate, lock.

## Mentor panel
Use:
94 Quality
✓ Story
✓ Continuity
⚠ Pacing
rather than a wall of errors.
Each issue includes evidence, impact and one-click fix.

## Motion
Use short, purposeful transitions:
opacity, translate, scale, clip-path, paper-slide, marker-draw.
Avoid constant floating/glow effects.

## Responsive
Desktop-first for production, but all core review and project actions remain usable on tablet.

## Accessibility
Keyboard navigation, focus states, reduced-motion mode, sufficient contrast, captions and readable Arabic.

## Empty states
Never say “No data”.
Say what the user can create and provide one strong CTA.

## Loading
Show meaningful pipeline stages:
Analyzing script → Building story → Planning scenes → Generating → Mentor review → Rendering.

## Premium rule
Every screen must have one clear visual hierarchy and one clear next action.
